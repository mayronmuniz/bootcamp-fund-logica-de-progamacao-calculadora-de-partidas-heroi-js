🏆 Calculadora de Partidas Rankeadas (8-Bits Edition)

Desafio de Lógica de Programação - DIO

📜 Sobre o Projeto

Este é o segundo projeto desenvolvido para o Bootcamp de Lógica de Programação da DIO.

Enquanto o primeiro desafio focava em estruturas de controle básicas, este projeto tem como objetivo principal a prática de Funções, Parâmetros e Retornos. Para tornar o aprendizado mais dinâmico, criei novamente uma Web Application com estética Retro RPG (8-Bits), onde o usuário pode simular o histórico de um jogador competitivo.

🎯 O Desafio

O objetivo é criar uma função que recebe como parâmetro a quantidade de vitórias e derrotas de um jogador, e depois disso retorna o resultado para o usuário.

A lógica implementada calcula o Saldo de Rankeadas (Vitórias - Derrotas) e determina o nível baseado na seguinte tabela:

Ferro: Vitórias < 10

Bronze: Vitórias entre 11 e 20

Prata: Vitórias entre 21 e 50

Ouro: Vitórias entre 51 e 80

Diamante: Vitórias entre 81 e 90

Lendário: Vitórias entre 91 e 100

Imortal: Vitórias ≥ 101

🎮 Funcionalidades

Interface Gráfica Retrô: Visual inspirado em jogos clássicos, totalmente responsivo.

Sistema de Funções: Código modularizado separando a lógica de cálculo (calcularSaldoENivel) da manipulação do DOM.

Interatividade: Personagem animado em SVG que reage ao cálculo do nível.

Efeitos Sonoros: Feedback auditivo em 8-bits gerado via JavaScript (Web Audio API).
